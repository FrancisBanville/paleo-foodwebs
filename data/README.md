# Description of the datasets

## Raw datasets

`interactions_Fezouata`: Full list of interactions in the Fezouata Shale network with their estimated level of certainty (1 = low level of certainty, 3 = high level of certainty).

`S1_Fezouata Shale Fauna`: Full taxa list of the Fezouata Shale. The phylum and sometimes a lower taxonomic classification are included for each taxon. Each taxon’s ecology is identified, as well as synonyms if there are any.

`S2_Lower Fezouata Shale Fauna`: Taxa list of the Lower Fezouata Shale. The phylum and sometimes a lower taxonomic classification are included for each taxon. Each taxon’s ecology is identified, as well as synonyms if there are any.

`S3_ Upper Fezouata Shale Fauna`: Taxa list of the Upper Fezouata Shale. The phylum and sometimes a lower taxonomic classification are included for each taxon. Each taxon’s ecology is identified, as well as synonyms if there are any.

`S4_Fauna in both formations`: Taxa found in both the Lower and Upper Fezouata Shales. The phylum and sometimes a lower taxonomic classification are included for each taxon. Each taxon’s ecology is identified, as well as synonyms if there are any.

`S5_Taxa used in network`: Taxa utilized to build the Lower Fezouata trophic network. The phylum and sometimes a lower taxonomic classification are included for each taxon. Each taxon’s ecology is identified, as well as synonyms if there are any.

Note that only the `interactions_Fezouata` dataset is used in the analyses. The other datasets provide complementary information on the taxa present in the Fezouata networks.


## Clean datasets

`network_Fezouata.jld2`: Unipartite network of the Fezouata Shale (original species), generated by the `code/01_clean_data.jl` script.

`network_Fezouata_trophicsp.jld2`: Unipartite network of the Fezouata Shale (trophic species), generated by the `code/02_convert_trophic_species.jl` script.

## Simulated datasets

This folder will contain the simulated networks for the Fezouata Shale, generated by the `03_simulate_networks.jl` script. 

It will include the simulated networks of species (`networks_fezouata_sim.jld2`) and the simulated networks of trophic species (`networks_fezouata_trophicsp_sim.jld2`), for three different ecological models (the cascade, niche, and nested-hierarchy models).

It does not currently contain the simulated networks as those files are too big to be stored here, but they can be provided upon demand. These files can also be recreated by running the code which automatically generates them.
