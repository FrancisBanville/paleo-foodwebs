# sim folder

This folder will contain the simulated networks for the Fezouata Shale, generated by the `03_simulate_networks.jl` script. 

It will include the simulated networks of species (`networks_fezouata_sim.jld2`) and the simulated networks of trophic species (`networks_fezouata_trophicsp_sim.jld2`), for three different ecological models (the cascade, niche, and nested-hierarchy models).

It does not currently contain the simulated networks as those files are too big to be stored here, but they can be provided upon demand. These files can also be recreated by running the code which automatically generates them.
