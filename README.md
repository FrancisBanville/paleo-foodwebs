# Paleo Food Webs 

Data and code repository for the manuscript entitled "A paleoecological trophic network model of the Early Ordovician Lower Fezouata Shale (Morocco) fossil fauna" (Soucy et al., 2026).

## Folder organization

`code/`: contains the Julia and R scripts that import, clean, and analyze the data and generate the figures.k

`data/`: contains the raw datasets and their description, as well as the clean and simulated datasets generated by the scripts.

`figures/`: contains all figures produced by the scripts and included in the manuscript and supplementary material.

`results/`: contains selected measures of network structure calculated for real and simulated networks and used to generate the figures


### Scripts

`main.jl` executes the whole code from start to finish. The `Manifest.toml` and `Project.toml` files contain all information about package versions and dependencies. They are updated automatically when installing new packages. Do *not* edit them manually. 

Scripts that execute specific tasks are in the code folder.

`01_clean_data.jl` imports the raw dataset of species interactions (`data/raw folder`) and converts it into a clean unipartite network (saved in the `data/clean folder`).

`02_convert_trophic_species.jl` builds networks of trophic species by grouping species that interact the same way (saved in the `data/clean folder`). 

`03_simulate_networks.jl` predicts networks using the niche, cascade, and nested-hierarchy models with the number of species and interactions of the empirical network (saved in the `data/sim folder`).

`04_compute_measures.jl` calculates selected measures of network structure for both predicted and empirical networks (saved in the `results/ecological_models` folder).

`05_make_ecomodels_figures.jl` produces figures comparing the structure of empirical and predicted networks (saved in the `figures/ecological_models` folder).

`06_create_uncertain_networks.jl` builds networks with different levels of interaction uncertainty and calculates selected measures of network structure (saved in the `results/uncertainty_analysis` folder).

`07_make_uncertainty_figures.R` produces figures comparing the structure of networks with different levels of interaction uncertainty (saved in the `figures/uncertainty_analysis` folder).

Home-made functions calculating measures of network structure are in the `code/functions` folder.

## Installation and execution

### Julia scripts

You need to have Julia v1.8.0 or higher to run the scripts. 
Julia can be downloaded [here](https://julialang.org/downloads/). 

We recommend that you use an editor like [VS Code](https://code.visualstudio.com/docs/languages/julia) to execute the code. 

### R script

R can be installed following the instructions provided by [Posit](https://docs.posit.co/ide/user/#rstudio-ide-oss-downloads). We used R 4.3.2 for this project.

We recommend that you use an editor like [VS Code](https://code.visualstudio.com/docs/languages/R) or [RStudio](https://posit.co/downloads) to execute the code.
